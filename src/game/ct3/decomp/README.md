# decomp/

손으로 디컴파일한 함수가 들어가는 자리다. 각 파일은 대체하는 lift 함수와 같은 심볼 `void sub_XXXXXXXX(void)`을 정의하고, `scripts/recomp/regenerate.py`(파이프라인은 `scripts/recomp/lifter.py`)가 그 정의를 lifter의 `--exclude-manual`로 넘긴다. 파일이 `extern void sub_XXXXXXXX_gen(void);`을 선언하면 lift 본문이 그 이름으로 남고, `rect3_decomp_check`(`tools/decomp_check/`)가 둘을 같은 게스트 상태에서 돌려 비교한다. 규칙은 [docs/CODING_STYLE.md](../../../../docs/CODING_STYLE.md)의 "재컴파일 코드와 디컴파일 코드" 항목이다.

|---|---|---|
| `d3dx_matrix.c` | `000E4B73` D3DXVec4Transform, `000E4BB9` D3DXMatrixMultiply, `000E4CB7` D3DXMatrixInverse(정체는 **추정**) | issue #27, [분석](../../../../docs/analysis/d3dx-matrix.md) |
| `adxm_lock.c` | `000B2FF0` ADXM lock 콜백, `000B3030` unlock 콜백(lift 본문을 호스트 잠금으로 감쌈), `000BB9C0` 잠금 모두 풀기(이 스레드의 깊이만큼), `000B9540` 레벨 2 서버 실행, `000B7EE0` SJ 링 리셋, `000B2A90` ADXF Close(같은 호스트 잠금 아래). 디컴파일이 아니라 호스트 동시성 어댑터 | issue #29, #42, #44, [분석](../../../../docs/analysis/cri-middleware.md), [설계 i042](../../../../docs/design/20261103-i042-cri-server-lock.md), [설계 i044](../../../../docs/design/20261106-i044-adxt-stop-lock.md) |

이 디렉터리의 파일을 더하거나 바꾸면 `regenerate.py`를 다시 돌리고, `rect3_decomp_check`에 경우를 더한다.

Hand-decompiled functions go here. Each file defines the same symbol as the lifted function it replaces, `void sub_XXXXXXXX(void)`, and `scripts/recomp/regenerate.py` (pipeline in `scripts/recomp/lifter.py`) hands those definitions to the lifter as `--exclude-manual`. A file that declares `extern void sub_XXXXXXXX_gen(void);` keeps the lifted body under that name, and `rect3_decomp_check` (`tools/decomp_check/`) runs the two from the same guest state and compares them. The rules are the "Recompiled and Decompiled Code" section of [docs/CODING_STYLE.md](../../../../docs/CODING_STYLE.md). Files: `d3dx_matrix.c`, the three D3DX matrix routines above (issue #27, [analysis](../../../../docs/analysis/d3dx-matrix.md)); `adxm_lock.c`, the CRI ADXM lock callbacks `000B2FF0` and `000B3030` wrapped in a host lock and the release-all loop `000BB9C0` releasing this thread's depth, and the level-2 server pass `000B9540`, the SJ ring reset `000B7EE0` and ADXF Close `000B2A90` under the same host lock, a host-concurrency adapter rather than a decompilation (issues #29, #42, #44, [analysis](../../../../docs/analysis/cri-middleware.md)); `sj_lock.c`, CRI's SJ critical section `000BC950`/`000BC970` wrapped in a host lock, also an adapter (issue #29, [design](../../../../docs/design/20261103-i029-sj-lock.md)). After adding or changing a file here, run `regenerate.py` again and add cases to `rect3_decomp_check`.
