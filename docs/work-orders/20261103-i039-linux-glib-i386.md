# 작업 지시: Linux 가이드의 i386 설치가 glib 2.80.0-6ubuntu3.10에서 멈춘다 (issue #39)

근거: rexbox #46([작업 로그](../../third_party/rexbox/docs/work-logs/20261103-i046-ci-glib-i386.md)). 코드 변경이 없는 가이드 수정이라, 설계는 그 작업 로그의 원인 절로 대신한다.

1. 작업 브랜치 `i039-linux-glib-i386`. 커밋 제목 끝에 `(#39)`.
2. `docs/guides/linux-setup-and-build.md`: x86 설치에 선행 설치(`libglib2.0-dev-bin qemu-user`)와 멈출 때의 증상을 더한다(한국어·영어).
3. `third_party/rexbox`를 v0.0.21로 올리고, ARCHITECTURE의 submodule 표기를 고친다.
4. 검증: WSL2 Ubuntu 24.04에서 가이드의 설치를 시뮬레이션한다(`apt-get install -s`). 근거가 된 실패는 rexbox CI 러너에서 재현·수정되었다.
5. 작업 로그.
