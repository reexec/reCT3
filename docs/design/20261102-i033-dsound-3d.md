# 설계: 3D 위치 사운드와 음성 headroom — rexbox #40을 따라감 (issue #33)

상태: 구현됨([작업 지시](../work-orders/20261102-i033-dsound-3d.md), [작업 로그](../work-logs/20261102-i033-dsound-3d.md)). 구현 설계: rexbox [설계 i040](../../third_party/rexbox/docs/design/20261102-i040-dsound-3d.md).

## 1. 요구사항

게임 소리가 부자연스럽다(사용자 보고). 데모 집계로, 게임은 3D 음성 약 50개와 음성별 headroom(효과음 600, 음악 0)을 쓰는데 rexbox 믹서는 둘 다 반영하지 않았다(**확인됨**).

## 2. 설계

* 구현은 공유 런타임 rexbox에서 한다(rexbox #40, v0.0.18). 이 저장소는 submodule을 올리고 확인만 한다. 공개 계약은 바뀌지 않아 재생성도 필요 없다.
* rexbox 쪽 내용: headroom(XDK 기본값 2D 600, 3D 0), 3D 음성(XDK 거리 감쇠, DirectSound cone과 도플러, HRTF 대신 균형 법칙 패닝), 믹스 빈의 전력 스테레오 접기(가운데 −3 dB, LFE 제외).

## 3. 검증

빌드·CTest, 숨김 데모, 사용자 청취.

# Design: 3D positional audio and voice headroom, following rexbox #40 (issue #33)

Status: implemented ([work order](../work-orders/20261102-i033-dsound-3d.md), [work log](../work-logs/20261102-i033-dsound-3d.md)). Implementation design: rexbox [design i040](../../third_party/rexbox/docs/design/20261102-i040-dsound-3d.md).

Requirement: the game sounds unnatural (user report); counting the demo's calls shows the game uses about 50 3D voices and per-voice headroom (effects 600, music 0), neither rendered by the rexbox mixer (**confirmed**). Design: the work is done in the shared runtime (rexbox #40, v0.0.18): headroom with the XDK defaults (2D 600, 3D 0), 3D voices (the XDK distance attenuation, DirectSound's cone and Doppler, a balance-law pan in place of the HRTF) and a power stereo fold-down of the mix bins (center −3 dB, LFE left out); this repository moves the submodule and checks; the public contract is unchanged and no regeneration is needed. Verification: build and CTest, a hidden demo, user listening.
