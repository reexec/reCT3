# 작업 로그: 일본판 XBE 등록, 분석, lift, 첫 실행 — 진행 중 (issue #3)

설계: [20261020-i001 §4·§5](../design/20261020-i001-project-bootstrap.md)(등록 절차와 위험) · 분석: [ct3-xbe-overview](../analysis/ct3-xbe-overview.md)

## 한 일

1. `register_xbe.py`로 일본판을 등록했다(MD5 `18a88739…`, title id `53450004`, XDK 4531). 게임 디렉터리 기본값을 `roms/`로 바꿨다(사용자 배치: `roms/default.xbe`, `roms/Media/`).
2. 분석 문서(`ct3-xbe-overview.md`, `XBE_DESIGN.*`): 헤더, 섹션 13개, 라이브러리 4531, 커널 import 121개(17개 HLE 없음), 자산 400개, 부팅 순서.
3. `regenerate.py`로 4,886개 함수를 lift했다(미해결 스텁 4, 미구현 명령 22). `hle_libraries.json`: D3D8·D3D8LTCG·DSOUND 전체 + XAPI 입력 함수 11개; `lifted`: `Get2DSurfaceDesc`, `XAudioDownloadEffectsImage`.
4. 앱: 바인딩 안 된 커널 import를 이름으로 찍고, fault 보고에 호스트 명령 주소를 더하며, rexbox의 물리 메모리 창을 켠다.
5. frontier를 차례로 넘겼다(모두 rexbox 변경): 디스크 인증 IOCTL(rexbox #6) → `D3DDevice_GetRenderTarget`(#7) → `Data | 0x80000000` fault(물리 메모리 창, #8) → `Get2DSurfaceDesc`(lifted 목록, #10) → DSOUND 4531 함수(#9: `XAudioDownloadEffectsImage`, `SetMixBinHeadroom`, `UseFullHRTF`).
6. (2차 세션) rexbox 브랜치 커밋으로 재생성해 `UseFullHRTF`를 넘겼다. `DirectSoundEnterCriticalSection`은 IRQL 확인 뒤 `RtlEnterCriticalSection`만 부르는 내부 함수라 `lifted`에 넣었다. 즉시값으로만 전달되는 스레드 작업 함수 `000B3110`/`000B3180`을 간접 호출할 때 대상이 없어 건너뛰어졌으므로, `find_pointer_targets.py --write`로 후보 29개를 `seed_pointer_targets.json`에 두었다(함수 4,886 → 4,929개). rexbox에 `D3DDevice_GetProjectionViewportMatrix`를 더했다(#7, rexbox `82f7714`).
7. (2차 세션, 이어서) rexbox에 `D3DDevice_SetVertexShaderInput`, `D3DDevice_SetModelView`를 더했다(#7, rexbox `c4e6a09`). 첫 프레임이 present되고 XInput 패드가 열린다.
8. (2차 세션, 이어서) rexbox에 푸시 버퍼 `BeginPush_4`/`EndPush`(설계 rexbox i007-push-buffer, `e5aa2e3`), `DirectSoundCreateBuffer`(`d0a8f4a`)를 더했다. 다음 정지점인 커널 `KeWaitForMultipleObjects`는 rexbox 작업 트리에서 구현했지만, 타이머 issue와 함께 커밋하려고 남겨 두었다.
9. (2차 세션, 이어서) rexbox [#12](https://github.com/reexec/rexbox/issues/12)를 열어 설계(`20261020-i012-kernel-timers-dpc`)대로 발화하는 커널 타이머, DPC 스레드, `KeWaitForMultipleObjects`를 넣었다(rexbox `97a8721`).
