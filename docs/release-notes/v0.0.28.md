## reCT3 v0.0.28

이전 릴리스 **v0.0.27** 이후의 변경입니다(issue #52). **드물게 약 11초씩 되풀이되던 멈춤을 고칩니다.** CRI가 safe thread를 깨우는 동안 ADXM 호스트 잠금을 쥐고 있어서, 그 잠금을 기다리는 safe thread와 교착이 났습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#52](https://github.com/reexec/reCT3/issues/52) | CRI safe thread 핸드셰이크(`000B3060`)와 ADXM 호스트 잠금의 교착 | `7635e72`, 이 PR |

### 바뀐 것

* `src/game/ct3/decomp/adxm_lock.c`: `sub_000B3060`을 rexbox의 새 C API `rexbox_guest_wait_begin`/`end`로 감싼다. 핸드셰이크가 도는 동안 게스트 잠금이 내려가, safe thread가 서버를 돌고 플래그를 지운다. Xbox에서 우선순위가 올라간 safe thread가 호출자를 선점하던 것과 같은 뜻이다([설계](../design/20261123-i052-safe-thread-handshake.md)).
* rexbox v0.0.30 → **v0.0.31**(rexbox #87: 위 C API).
* 문서: 설계·작업 지시·작업 로그 i052, 분석 `cri-middleware.md` §5, `decomp/README.md`, ARCHITECTURE.

### 확인한 것

| 구성 | 확인 |
|---|---|
| Win32 x86 Release | 경고 0(D9025 제외), CTest 7/7 |
| 숨긴 데모 6개 동시 실행 | 수정 전 48번 중 교착 1번 → 수정 후 48번 중 0번 |

### 알려진 한계

* 효과음 스트림이 드물게 멈춘다(기존). 영상 구간의 null 간접 호출 `000C967E`(기존).
* 이 버전으로 올린 뒤 `git submodule update`와 `scripts/recomp/regenerate.py`를 다시 실행해야 한다(새 대체 함수 `000B3060`).

## reCT3 v0.0.28 (English)

Changes since **v0.0.27** (issue #52). **Fixes a rare stop that repeated for about 11 s at a time**: CRI held the ADXM host lock while waking its safe thread, which deadlocked with the safe thread waiting for that lock.

Issue: #52, the deadlock between CRI's safe-thread handshake (`000B3060`) and the ADXM host lock (`7635e72`, this PR).

Changes:

* `src/game/ct3/decomp/adxm_lock.c` wraps `sub_000B3060` in rexbox's new C API `rexbox_guest_wait_begin`/`end`. While the handshake spins the guest locks are down, so the safe thread runs its server and clears the flag: the same meaning as the raised safe thread preempting the caller on the Xbox ([design](../design/20261123-i052-safe-thread-handshake.md)).
* rexbox v0.0.30 → **v0.0.31** (rexbox #87: the C API above).
* Documents: design, work order and work log i052, the analysis `cri-middleware.md` section 5, `decomp/README.md`, ARCHITECTURE.

Verified: Win32 x86 Release with no warnings (apart from D9025), CTest 7/7. Six hidden demos in parallel: one deadlock in 48 runs before the fix, none in 48 after. A drive: 59.5–59.8 fps, no issues.

Known limits:

* Effect streams rarely stop (existing); the null indirect call `000C967E` in the movie (existing).
* After moving to this version, run `git submodule update` and `scripts/recomp/regenerate.py` again (new replacement `000B3060`).
* Windows Defender may flag the built `rect3.exe` as `Trojan:Win32/Bearfoos.B!ml` (a machine-learning verdict); excluding the build folder avoids it.
