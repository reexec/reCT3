## reCT3 v0.0.20

이전 릴리스 **v0.0.19** 이후의 변경입니다(issue #39). **Linux 가이드의 x86(i386) 패키지 설치가 Ubuntu 24.04의 glib 2.80.0-6ubuntu3.10에서도 됩니다.** rexbox를 v0.0.21로 올립니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#39](https://github.com/reexec/reCT3/issues/39) | Linux 가이드의 i386 설치가 glib 3.10에서 멈춤 | `8d0039b` |

### 바뀐 것

* `docs/guides/linux-setup-and-build.md`: x86 설치 앞에 `sudo apt-get install -y libglib2.0-dev-bin qemu-user`. glib 3.10의 개발 파일은 `python3 | qemu-user | qemu-user-static`에 의존하고, i386 패키지에서 이 `python3`는 i386 `python3`라 설치된 amd64 Python과 충돌한다(`held broken packages`).
* **rexbox v0.0.20 → v0.0.21**(`bc21519`, reexec/rexbox#46): CI와 릴리스 워크플로의 Linux x86 작업에 같은 선행 설치. 코드 변경은 없다.
* 문서: 작업 지시·작업 로그 i039, ARCHITECTURE의 submodule 표기.

### 확인한 것

| 구성 | 확인 |
|---|---|
| WSL2 Ubuntu 24.04 | 가이드 설치 시뮬레이션이 풀림 |
| rexbox CI | Linux x86 Debug·Release 포함 6개 작업 통과, v0.0.21 릴리스 워크플로 통과 |

### 알려진 한계

* 재생성은 필요 없다.

## reCT3 v0.0.20 (English)

Changes since **v0.0.19** (issue #39). **The Linux guide's x86 (i386) package install works with Ubuntu 24.04's glib 2.80.0-6ubuntu3.10.** rexbox moves to v0.0.21.

Issue: #39, the Linux guide's i386 install stopped on glib 3.10 (`8d0039b`).

Changes: `docs/guides/linux-setup-and-build.md` runs `sudo apt-get install -y libglib2.0-dev-bin qemu-user` before the x86 install; glib 3.10's development files depend on `python3 | qemu-user | qemu-user-static`, which for an i386 package is `python3:i386` and clashes with the installed amd64 Python (`held broken packages`). rexbox v0.0.20 → v0.0.21 (`bc21519`, reexec/rexbox#46): the same first step in the Linux x86 jobs of CI and the release workflow, no code change. Documents: work order and work log i039, the submodule entry in ARCHITECTURE.

Verified: the guide's install resolves in simulation on WSL2 Ubuntu 24.04; rexbox's CI passes all six jobs, Linux x86 Debug and Release among them, and its v0.0.21 release workflow passes. No regeneration is needed.
