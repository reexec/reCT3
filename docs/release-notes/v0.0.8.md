## reCT3 v0.0.8

이전 릴리스 **v0.0.7** 이후의 변경입니다(issue #14). **rexbox를 v0.0.8에 고정합니다. 타이틀에서 Start를 누르면 `REXBOX_HLE_FALLBACK` 없이 게임플레이(모드 선택 → 코스 → 운전)까지 갑니다.**

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#14](https://github.com/reexec/reCT3/issues/14) | Start 뒤 미구현 `D3DDevice_InsertFence`(`000F5050`)에서 멈춤. rexbox #19 | `166b7bf` 및 이 릴리스 커밋 |

### 바뀐 것

* **submodule**: `third_party/rexbox`를 v0.0.8(`508fc43`, rexbox `main`의 머지 커밋)에 고정한다. rexbox v0.0.8에 D3D8 펜스 export(`InsertFence`, `BlockOnFence`, `IsFencePending`)가 생겼다. 펜스는 넣는 즉시 완료로 처리된다.
* **원인**: 프레임 코드 `0005E7B8`이 `InsertFence`를, `0005E859`가 그 펜스로 `BlockOnFence`를 부른다. 4531 라이브러리에서 `InsertFence`는 `D3D_SetFence(0)`, `BlockOnFence(f)`는 `D3D_BlockOnTime(f, 0)`이다.
* **분석**: §7에 펜스 호출 항목과 부팅 순서도의 한 단계를 더했다.

### 확인한 것

| 구성 | 확인 |
|---|---|
| Win32 x86 Release | 빌드 오류 0, CTest 5/5 |
| v0.0.7 exe, Start | 스레드 2가 `D3DDevice_InsertFence`에서 멈춤 |
| 이 버전, `REXBOX_HLE_FALLBACK` 없음 | 모드 선택 → West Coast → 로딩 팁 → 운전. 미구현 HLE 정지 없음 |
| 입력 없는 운전 | 23~27 fps. 제한 시간이 실제 시간의 약 0.43배로 흐른다 |

### 알려진 한계

* 게임 속도는 fps/60이다. 운전 중 프레임률이 60에 못 미쳐 아직 실시간보다 느리다.
* 운전 중 화면 오류는 이 작업에서 보지 않았다.
* 이 버전으로 올린 뒤 `git submodule update --recursive`를 하고 다시 빌드한다(재생성 필요 없음).

## reCT3 v0.0.8 (English)

Changes since **v0.0.7** (issue #14). **rexbox is pinned to v0.0.8: Start on the title screen reaches gameplay (mode selection → course → driving) without `REXBOX_HLE_FALLBACK`.**

Resolved: #14, the stop at the unimplemented `D3DDevice_InsertFence` (`000F5050`) after Start; rexbox #19 (`166b7bf` and this release's commit).

Changes: `third_party/rexbox` is pinned to v0.0.8 (`508fc43`, the merge commit on rexbox's `main`), which adds the D3D8 fence exports (`InsertFence`, `BlockOnFence`, `IsFencePending`) and treats a fence as complete once inserted. The cause: the frame code `0005E7B8` calls `InsertFence` and `0005E859` calls `BlockOnFence` on that fence; in the 4531 library `InsertFence` is `D3D_SetFence(0)` and `BlockOnFence(f)` is `D3D_BlockOnTime(f, 0)`. Analysis section 7 gained the fence calls and a step in the boot sequence diagram.

Verified: Win32 x86 Release with no build errors and CTest 5/5; the v0.0.7 exe stops on thread 2 at `D3DDevice_InsertFence` after Start; this version, without `REXBOX_HLE_FALLBACK`, goes through mode selection, West Coast and a loading tip to driving with no unimplemented-HLE stop; driving with no input runs at 23–27 fps, so the time limit runs at about 0.43× real time.

Known limits: game speed is fps/60 and driving is still below 60 fps, so slower than real time. Rendering faults while driving were not examined. After updating, run `git submodule update --recursive` and rebuild (no regeneration needed).
