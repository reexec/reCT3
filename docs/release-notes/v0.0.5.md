## reCT3 v0.0.5

이전 릴리스 **v0.0.4** 이후의 변경입니다(issue #9). **rexbox를 머지된 v0.0.5에 고정하고, 캐시된 지형 자산을 읽어 도시를 그립니다.**

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#9](https://github.com/reexec/reCT3/issues/9) | 캐시 자산 `bank10.mdl`의 이름 바꾸기(rexbox #14), 지형이 그려짐 | `60fcf10` |

### 바뀐 것

* **submodule**: `third_party/rexbox`를 v0.0.5(`b22db2c`, rexbox `main`의 머지 커밋)에 고정한다. rexbox v0.0.5는 `NtSetInformationFile`의 `FileRenameInformation`을 처리한다.
* **원인**: 타이틀은 `D:\Media\bank10.mdl`을 가공해 `Z:\tmp`에 쓰고 XAPI `MoveFileEx`로 `Z:\_bank10.mdl`로 바꾼 뒤 연다. 이름 바꾸기가 실패해 이 자산이 로드되지 않았고, 도로와 건물이 그려지지 않았다.
* **분석·문서**: 분석 문서 §7, 작업 지시와 작업 로그.

### 확인한 것

| 구성 | 확인 |
|---|---|
| Win32 x86 Release | 빌드 오류 0, CTest 5/5(rexbox kernel probe 94개 검사) |
| `rect3.exe roms`(hidden, 100초, 캐시 삭제 후) | 이름 바꾸기와 이어지는 열기 성공. 데모 frame 1500에 실내 주차장(바닥, 천장 조명, 벽, 기둥)이 그려진다 |

### 알려진 한계

* 지형이 그려지는 구간의 프레임 시간이 고르지 않다(평균 22 fps, 600프레임 중 406프레임이 33.4 ms 초과). 다음 작업에서 본다.
* 이 버전으로 올린 뒤 `git submodule update --recursive`를 하고 다시 빌드한다(생성 코드는 바뀌지 않으므로 재생성은 필요 없다). 이전 실행에서 남은 `hdd/Partition5/tmp`는 지워도 된다.
* rexbox의 Linux CI는 러너의 i386 패키지 설치 문제로 v0.0.3부터 돌지 않는다(이 저장소의 CI는 Win32만 돈다).

## reCT3 v0.0.5 (English)

Changes since **v0.0.4** (issue #9). **rexbox is pinned to the merged v0.0.5, and the cached geometry asset loads, so the city is drawn.**

Resolved: #9, renaming the cached asset `bank10.mdl` (rexbox #14) so its geometry draws (`60fcf10`).

Changes: `third_party/rexbox` is pinned to v0.0.5 (`b22db2c`, the merge commit on rexbox's `main`), which handles `NtSetInformationFile`'s `FileRenameInformation`. The cause: the title processes `D:\Media\bank10.mdl` into `Z:\tmp`, renames it to `Z:\_bank10.mdl` with XAPI `MoveFileEx` and opens it; the rename failed, the asset never loaded, and roads and buildings were missing. Analysis section 7, the work order and the work log are updated.

Verified: Win32 x86 Release with no build errors and CTest 5/5 (rexbox kernel probe, 94 checks); `rect3.exe roms` (hidden, 100 s, cache cleared) renames and then opens the asset, and demo frame 1500 draws an indoor car park (floor, ceiling lights, walls, pillars).

Known limits: frame times are uneven where the geometry draws (22 fps on average, 406 of 600 frames over 33.4 ms), the next task. After updating, run `git submodule update --recursive` and rebuild (the generated code does not change, so no regeneration); a `hdd/Partition5/tmp` left from earlier runs can be deleted. rexbox's Linux CI has not run since v0.0.3 because the runner's i386 package install fails (this repository's CI runs Win32 only).
