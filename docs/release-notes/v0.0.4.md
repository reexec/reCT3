## reCT3 v0.0.4

이전 릴리스 **v0.0.3** 이후의 변경입니다(issue #7). **어트랙트 데모 중 화면 갱신이 멈추던 문제를 고칩니다.**

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#7](https://github.com/reexec/reCT3/issues/7) | `fmod` 분류 테이블 항목 `000E9C7C`, `000E9D1E` lift(데모 중 멈춤) | `10a0b10` |

### 바뀐 것

* **seed**: CRT `fmod`의 피연산자 분류 테이블(`.data 002148A0`)에서 테이블로만 도달하는 항목 `000E9C7C`와 `000E9D1E`를 `seed_pointer_targets.json`에 넣었다. 빠져 있으면 `indirect call to 000E9C7C has no target`로 호출이 건너뛰어지고 x87 스택이 틀어져 present가 멈췄다.
* **분석·문서**: 분석 문서 §7, 작업 지시와 작업 로그.
* **submodule**: 변경 없음(`third_party/rexbox` v0.0.4 `0fce514`, `third_party/xboxrecomp` v0.15.0).

### 확인한 것

| 구성 | 확인 |
|---|---|
| Win32 x86 Release | 빌드 오류 0, CTest 5/5 |
| `rect3.exe roms`(호스트 오디오, hidden, 90초) | `no target`·`[stall]` 없음 |

### 알려진 한계

* 멈춤은 실행 타이밍에 따라 나타나므로 한 번의 실행으로 완전히 배제하지는 못한다. 창을 띄운 실행은 사용자 환경에서 확인한다.
* rexbox의 `find_pointer_targets.py`는 이런 CRT 분류 테이블을 후보로 내지 않는다.
* 생성 코드는 저장소에 없으므로 이 버전으로 올린 뒤 `scripts/recomp/regenerate.py`를 다시 실행해야 한다.

## reCT3 v0.0.4 (English)

Changes since **v0.0.3** (issue #7). **Fixes presenting stopping during the attract demo.**

Resolved: #7, lifting `fmod`'s class-table entries `000E9C7C` and `000E9D1E` (the demo stall; `10a0b10`).

Changes: the entries `000E9C7C` and `000E9D1E` of the CRT `fmod` operand-class table (`.data 002148A0`), reached only through the table, are seeded in `seed_pointer_targets.json`; without them the call was skipped with `indirect call to 000E9C7C has no target`, the x87 stack went wrong and presenting stopped. Analysis section 7, the work order and the work log are updated. Submodules unchanged (`third_party/rexbox` v0.0.4 `0fce514`, `third_party/xboxrecomp` v0.15.0).

Verified: Win32 x86 Release with no build errors and CTest 5/5; `rect3.exe roms` on host audio, hidden, 90 s, with no `no target` and no `[stall]`.

Known limits: the stall depends on run timing, so one run cannot rule it out entirely; a run with the window shown is checked on the user's machine. rexbox's `find_pointer_targets.py` does not list such CRT class tables. Generated code is not in the repository, so run `scripts/recomp/regenerate.py` again after updating to this version.
