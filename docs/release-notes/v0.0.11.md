## reCT3 v0.0.11

이전 릴리스 **v0.0.10** 이후의 변경입니다(issue #22). **xboxrecomp 파이프라인을 이 저장소로 옮기고 rexbox를 v0.0.11에 고정했습니다. rexbox는 이제 lifter를 모릅니다(rexbox #26).**

### issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#22](https://github.com/reexec/reCT3/issues/22) | rexbox #26을 따라 xboxrecomp 파이프라인을 이 저장소로 옮김 | `b0fc896` 및 이 릴리스 커밋 |

### 바뀐 것

* **submodule**: `third_party/rexbox`를 v0.0.11(`d532817`, rexbox `main`의 머지 커밋)에 고정한다. rexbox는 xboxrecomp submodule, `REXBOX_XBOXRECOMP_DIR`, `rexbox_check_license`, 재컴파일 스크립트를 지웠다.
* **파이프라인**: 새 `scripts/recomp/lifter.py`가 이 저장소의 xboxrecomp(upstream v0.15.0)를 실행하고 그 출력을 읽는다. `regenerate.py`, `check_hle_pops.py`, `find_pointer_targets.py`는 이 모듈과 rexbox의 보조 함수(`hle_overrides`, `hle_pops`, `pointer_targets`, `xbe_variant`)를 부른다.
* **CMake**: `REXBOX_XBOXRECOMP_DIR`와 `rexbox_check_license` 호출을 지웠다. rexbox는 lifter ABI의 자기 쪽(`recomp_abi.c`)을 생성 코드 옆의 `recomp_types.h`로 컴파일한다(`rect3_recomp_abi`).
* **규칙**: xboxrecomp의 LGPL 파일은 어떤 타깃의 소스 목록에도 넣지 않는다(AGENTS.md). 검사 코드는 없다.
* 설계: [20261024-i022-lifter-pipeline](../design/20261024-i022-lifter-pipeline.md).

### 확인한 것

| 구성 | 확인 |
|---|---|
| 재생성(ct3_jp), 이전 출력과 비교 | lift된 C가 바이트 단위로 같다. `check_hle_pops`(불일치 0), `find_pointer_targets`(후보 6) 출력도 같다 |
| Win32 x86 Release | 빌드 오류 0, `recomp_abi.c` /W4 경고 0 |
| 운전(`drive_west_coast.ps1`, 숨긴 창) | West Coast 운전 도달, 그리기 약 790, 59 fps, 정지 없음 |

### 알려진 한계

* 어트랙트 데모 중 드문 정지(issue #18, 열림).
* 이 버전으로 올린 뒤 `git submodule update --recursive`를 하고 다시 빌드한다. **재생성은 필요 없다.**

## reCT3 v0.0.11 (English)

Changes since **v0.0.10** (issue #22). **The xboxrecomp pipeline moved into this repository, and rexbox is pinned to v0.0.11; rexbox no longer knows the lifter (rexbox #26).**

Issue: #22, moving the xboxrecomp pipeline into this repository, following rexbox #26 (`b0fc896` and this release's commit).

Changes:
* `third_party/rexbox` is pinned to v0.0.11 (`d532817`, the merge commit on rexbox's `main`). rexbox dropped its xboxrecomp submodule, `REXBOX_XBOXRECOMP_DIR`, `rexbox_check_license` and its recompilation scripts.
* The new `scripts/recomp/lifter.py` runs this repository's xboxrecomp (upstream v0.15.0) and reads its output. `regenerate.py`, `check_hle_pops.py` and `find_pointer_targets.py` call it and rexbox's helpers (`hle_overrides`, `hle_pops`, `pointer_targets`, `xbe_variant`).
* CMake no longer sets `REXBOX_XBOXRECOMP_DIR` or calls `rexbox_check_license`. rexbox compiles its side of the lifter ABI (`recomp_abi.c`) against the `recomp_types.h` next to the generated code (`rect3_recomp_abi`).
* The rule that xboxrecomp's LGPL files never go into any target's source list stays in AGENTS.md; no code checks it.
* Design: [20261024-i022-lifter-pipeline](../design/20261024-i022-lifter-pipeline.md).

Verified:
* Regenerating ct3_jp and comparing with the previous output: the lifted C is byte-identical, and so is the output of `check_hle_pops` (0 mismatches) and `find_pointer_targets` (6 candidates).
* Win32 x86 Release has no build errors, and `recomp_abi.c` compiles at /W4 with 0 warnings.
* `drive_west_coast.ps1` with a hidden window reaches West Coast driving (about 790 draws, 59 fps, no stop).

Known limits:
* The rare attract-demo stop (issue #18) is still open.
* After updating, run `git submodule update --recursive` and rebuild. **No regeneration is needed.**
