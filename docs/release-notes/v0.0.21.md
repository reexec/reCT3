## reCT3 v0.0.21

이전 릴리스 **v0.0.20** 이후의 변경입니다(issue #42). **로딩 화면에서 게임이 가끔 멈추던 문제를 고칩니다.** v0.0.18(#29의 SJ 잠금) 이후 약 10%의 로딩에서 음악이 끊기고 화면이 멈췄습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#42](https://github.com/reexec/reCT3/issues/42) | 로딩 화면 멈춤: CRI vsync 스레드가 오류 트랩에서 SJ 잠금을 쥔 채 멈춤 | `72b11d3`, `552bb72`, `34a0c68` |

### 바뀐 것

* `src/game/ct3/decomp/adxm_lock.c`: 레벨 2 서버 실행(`000B9540`, ADX 디코드·출력과 AIX 분리)과 SJRBF 리셋(`000B7EE0`)을 ADXM 호스트 잠금 아래에 둔다. ADXT 정지가 SVM 잠금을 놓은 뒤 입력 링을 리셋하는데, 그것이 ADX 디코더가 그 링의 조각을 쥔 사이에 끼어들어 장부가 깨지고 CRI 오류 트랩(`jmp $`)에 빠졌다. Xbox에서는 서버 실행이 게임 스레드보다 높은 우선순위라 끼어들 수 없었다([설계](../design/20261103-i042-cri-server-lock.md)).
* 분석 `docs/analysis/cri-middleware.md`: SJ 링 레인 수의 짝과 −3을 내는 함수(UngetChunk)를 바로잡고, 서버·정지 경로를 더했다. `decomp/README.md`, ARCHITECTURE.
* 문서: 설계·작업 지시·작업 로그 i042.

## reCT3 v0.0.21 (English)

Changes since **v0.0.20** (issue #42). **Fixes the game sometimes stopping at a loading screen**, where since v0.0.18 (#29's SJ lock) about 10% of loads cut the music and froze the picture.

Issue: #42, the loading-screen hang, CRI's vsync thread stuck in an error trap holding the SJ lock (`72b11d3`, `552bb72`, `34a0c68`).

Changes: `src/game/ct3/decomp/adxm_lock.c` puts the level-2 server pass (`000B9540`: ADX decode and output, the AIX demultiplexer) and the SJRBF reset (`000B7EE0`) under the ADXM host lock. ADXT's stop resets the input ring after leaving its SVM lock; landing while the ADX decoder held a chunk of that ring, it broke the ring's books and sent CRI into its error trap (`jmp $`); on the Xbox the server pass ran above the game thread and could not be interrupted ([design](../design/20261103-i042-cri-server-lock.md)). The analysis `docs/analysis/cri-middleware.md` corrects the SJ ring's lane-count pairing and the function that reports −3 (UngetChunk) and adds the server and stop paths; `decomp/README.md`, ARCHITECTURE; design, work order and work log i042.

Verified: Win32 x86 Release with 0 warnings (apart from the generated code's existing D9025) and CTest 7/7; batches of six hidden demos in parallel: traps and music stops in 4 of 42 runs before, 0 of 42 after (24 instrumented, 18 final); two drives into gameplay (21:9, render scale 4, MSAA 16x) were fine.

Known limits: the null indirect call in the movie (`000C967E`) looks like a separate CRI race and remains (rare). After moving to this version run `scripts/recomp/regenerate.py` again (new replacements `000B9540`, `000B7EE0`). Windows Defender may flag the built `rect3.exe` as `Trojan:Win32/Bearfoos.B!ml` (a machine-learning verdict); excluding the build folder avoids it.
