## reCT3 v0.0.17

이전 릴리스 **v0.0.16** 이후의 변경입니다(issue #35, #29). **rexbox를 v0.0.19로 올려 오프닝의 바퀴 불꽃을 그리고, 음악이 반복될 때 기본 로그에 진단을 남깁니다.**

### 관련 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#35](https://github.com/reexec/reCT3/issues/35) | 오프닝의 바퀴 불꽃(rexbox [#42](https://github.com/reexec/rexbox/issues/42): render state로 쓴 combiner 상수) | 이 릴리스의 커밋 |
| [#29](https://github.com/reexec/reCT3/issues/29) (열려 있음) | 음악 반복의 기본 로그 진단(rexbox [#43](https://github.com/reexec/rexbox/issues/43)) | 이 릴리스의 커밋 |

### 바뀐 것

* `third_party/rexbox`: v0.0.18(`08742ce`) → v0.0.19(`7704477`).
  * 게임이 NV2A `COMBINER_FACTOR0/1`로 쓰는 combiner 상수를 반영한다. 오프닝 해변의 바퀴 불꽃, 잔디 위 불꽃 꼬리, 택시를 둘러싼 불꽃이 그려진다.
  * 스트림 루프 버퍼가 다시 채워지지 않으면 `[dsound] buffer ... its writer stopped`, 게스트 스레드 상태, 호스트 콜스택(Linux)을 한 번 남긴다.
* 문서: 설계·작업 지시·작업 로그 i035, i029 작업 로그(데모에서도 재현됨), Linux 가이드(반복 시 로그를 issue에 붙이기), ARCHITECTURE의 submodule 표기.

### 확인한 것

### 알려진 한계

* 음악 반복(issue #29)은 남아 있다. 이제 데모에서도 재현되고 로그에 보고된다.
* 잔디 위 불꽃 꼬리의 초록빛이 원본과 같은지는 확인하지 않았다.
* 재생성은 필요 없다. 다시 빌드만 한다.

## reCT3 v0.0.17 (English)

Changes since **v0.0.16** (issues #35, #29). **Moves rexbox to v0.0.19: the opening's wheel flames are drawn, and a music repeat leaves a diagnosis in the default log.**

Issues: #35, the opening's wheel flames (rexbox #42, combiner constants written as render states); #29 (still open), the default-log diagnosis of the music repeat (rexbox #43); the commits of this release.

Changes: `third_party/rexbox` from v0.0.18 (`08742ce`) to v0.0.19 (`7704477`): the combiner constants the game writes as NV2A `COMBINER_FACTOR0/1` apply, so the beach scene's wheel flames, the flame trail on the grass and the flames around the taxi are drawn; a streamed loop buffer no longer refilled gets one `[dsound] buffer ... its writer stopped` report with the guest thread states and host stacks (Linux). Documents: design, work order and work log i035, the i029 work log (the demo reproduces it too), the Linux guide (attach the log to the issue on a repeat), and ARCHITECTURE's submodule line.

Verified: Linux x64 Release with 0 warnings and CTest 7/7; in the demo the wheel flames are drawn (user confirmed) and the stalled-stream report fires once with no false positive.

Known limits: the music repeat (issue #29) remains, now reproduced in the demo and reported in the log; the grass trail's green tint was not compared with the original; no regeneration is needed, only a rebuild.
