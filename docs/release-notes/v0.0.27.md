## reCT3 v0.0.27

이전 릴리스 **v0.0.26** 이후의 변경입니다(issue #51). **lifter xboxrecomp를 v0.18.0으로 올립니다.** CT3에서는 생성 결과가 기능상 v0.17.0과 같아서, 동작은 바뀌지 않습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#51](https://github.com/reexec/reCT3/issues/51) | xboxrecomp v0.18.0 적용 검토와 적용 | 이 PR |

### 바뀐 것

* `third_party/xboxrecomp`: upstream v0.17.0 → **v0.18.0**(`37b61d5`, "Wrong Grain").
  * 생성 C에서 바뀐 것은 41개 함수의 57줄이다. x87 초월 함수(`fpatan`·`fyl2x`·`f2xm1`)가 `recomp_atan2`·`recomp_log2`·`recomp_expm1` 래퍼를 부르고, 기본 설정에서는 같은 libm 호출로 inline된다. 나머지는 `fnclex` 주석 문구다.
  * v0.18.0이 새로 lift하는 명령(xmm 정수 비트 연산, xmm `movq`, x87 스택 포인터)과 FCMOV·재동기 수정은 CT3에 해당하는 곳이 없다.
  * 함수, 경계, override, dispatch, 미구현 목록은 같다.
* 문서: 설계·작업 지시·작업 로그 i051, 버전을 적은 문서(README, PROJECT_CHARTER, THIRD_PARTY_NOTICES, ARCHITECTURE, Win32 가이드).
* #49가 남긴 Windows 기계의 Win32 x86 빌드·실행 확인을 이번 검토에서 마쳤다.

### 확인한 것

| 구성 | 확인 |
|---|---|
| Win32 x86 Release | 경고 0(D9025 제외), CTest 7/7 |
| 생성 | 오류 0. 고정을 올린 뒤의 생성물이 실험 생성물과 경로 주석을 빼면 같다 |
| 숨긴 데모 6개 동시 실행 | v0.17.0 24번 멈춤 0, v0.18.0 24번 중 1번은 기존 경쟁(#52) |
| 주행 | 59.4~59.8 fps, 이상 없음 |

### 알려진 한계

* #52: CRI safe thread 깨우기(`000B3060`)가 ADXM 호스트 잠금을 쥔 채 돌아, 드물게 약 11초씩 멈춘다(xboxrecomp와 상관없는 기존 경쟁).
* 이 버전으로 올린 뒤 `git submodule update`와 `scripts/recomp/regenerate.py`를 다시 실행해야 한다.
* Windows Defender가 빌드한 `rect3.exe`를 `Trojan:Win32/Bearfoos.B!ml`(머신러닝 판정)로 오탐할 수 있다. 빌드 폴더를 제외에 두면 된다.

## reCT3 v0.0.27 (English)

Changes since **v0.0.26** (issue #51). **The lifter xboxrecomp moves to v0.18.0.** For CT3 the generated result is functionally the same as v0.17.0's, so behavior does not change.

Issue: #51, reviewing and adopting xboxrecomp v0.18.0 (this PR).

Changes:

* `third_party/xboxrecomp`: upstream v0.17.0 → **v0.18.0** (`37b61d5`, "Wrong Grain").
  * 57 lines in 41 functions of the generated C changed: the x87 transcendentals (`fpatan`, `fyl2x`, `f2xm1`) call the `recomp_atan2`, `recomp_log2` and `recomp_expm1` wrappers, which inline to the same libm calls by default; the rest is the wording of an `fnclex` comment.
  * The instructions v0.18.0 newly lifts (xmm integer bitwise, xmm `movq`, x87 stack pointer) and the FCMOV and resync fixes have no site in CT3.
  * Functions, bounds, overrides, the dispatch and the unimplemented list are the same.
* Documents: design, work order and work log i051, and the documents that name the version (README, PROJECT_CHARTER, THIRD_PARTY_NOTICES, ARCHITECTURE, the Win32 guide).
* The Win32 x86 build and run on a Windows machine that #49 left open was done in this review.

Verified: Win32 x86 Release with no warnings (apart from D9025), CTest 7/7. Generation without errors; after moving the pin the output equals the experiment's apart from path comments. Six hidden demos in parallel: v0.17.0 no stops in 24 runs, v0.18.0 one in 24, an existing race (#52). A drive: 59.4–59.8 fps, no issues.

Known limits:

* #52: CRI's safe-thread wake-up (`000B3060`) spins holding the ADXM host lock, so the game rarely stops for about 11 s at a time (an existing race unrelated to xboxrecomp).
* After moving to this version, run `git submodule update` and `scripts/recomp/regenerate.py` again.
* Windows Defender may flag the built `rect3.exe` as `Trojan:Win32/Bearfoos.B!ml` (a machine-learning verdict); excluding the build folder avoids it.
