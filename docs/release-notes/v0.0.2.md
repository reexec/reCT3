### 바뀐 것

* **등록과 lift**: 일본판(MD5 `18a88739…`, title id `53450004`)을 등록하고, 함수 4,929개를 lift한다. 포인터로만 닿는 함수 29개는 시드로 두고, `lifted` 목록과 추가 심볼(`D3DDevice_SetVertexBlendModelView`)을 쓴다.
* **프로파일**: `D3D_InitializeDeviceState` = `0x000FAA20`, `D3D_g_Stream` = `0x00104ED8`.
* **분석**: `docs/analysis/ct3-xbe-overview.md`. XDK 4531의 렌더 상태 배치(슬롯 82 추가), 기본 상태 루틴, 팔레트, 푸시 버퍼, `SetRenderState_Simple`의 NV2A 메서드 표, 커널 타이머·DPC 경로를 다룬다.
* **rexbox**(이 저장소가 고정한 커밋에 들어간 것): 물리 메모리 창, SCSI pass-through, 커널 타이머·DPC·`KeWaitForMultipleObjects`, DSOUND 4531 함수, D3D8의 4531 렌더 상태 배치·푸시 버퍼·팔레트·P8·NORMPACKED3·declaration만 있는 셰이더 등.

### submodule

* `third_party/rexbox`는 rexbox 작업 브랜치 `i008-physical-window`의 커밋 `ed2a8c1`에 고정되어 있다. **임시 고정이다.** rexbox에서 그 브랜치가 머지되면(rexbox issue #7, #8, #9, #10, #12) 머지 커밋이나 태그로 옮긴다.
* `third_party/xboxrecomp`는 v0.15.0(`6376eb8`).

### 알려진 한계

* 포그를 아직 그리지 않는다. 여러 모델뷰 행렬의 정점 블렌딩은 첫 행렬만 쓴다. 이 둘은 다음 작업이다.
* 화면 확인은 hidden 디스플레이의 프레임 덤프로 했다. 창 표시, 소리, 입력으로 하는 실제 플레이는 아직 확인하지 않았다.

## reCT3 v0.0.2 (English)

The first release (issues #1, #2, #3). **Crazy Taxi 3: High Roller (Japan, XDK 4531) boots on the shared rexbox runtime and draws its logos, title screen, PRESS START and the attract demo's 3D scene.**

Resolved: #1, the project bootstrap (rexbox submodule, upstream xboxrecomp v0.15.0, CMake layers, the app, documents; `5f66504`, `77eb7dc`, `92e8075`); #2, GitHub Actions (build and CTest on `main`, tag verification, releases from a tag and its release note; `1daf6dd`); #3, registering, analyzing, lifting and first running the Japan XBE through to the 3D scene (`1330a7d`, `9e28fd9`, `0d88b02`, `5563574`, `9ac787c`, `4012b92`, `3faae7e`, `583ecb1`, `0b649d0`, `adb402a`, `0a29dde`).

Changes: the Japan build is registered (MD5 `18a88739…`, title id `53450004`) and 4,929 functions lifted, with 29 pointer-only seeds, the `lifted` list and an extra symbol (`D3DDevice_SetVertexBlendModelView`); the profile binds `D3D_InitializeDeviceState` = `0x000FAA20` and `D3D_g_Stream` = `0x00104ED8`; `docs/analysis/ct3-xbe-overview.md` covers XDK 4531's render-state layout (the added slot 82), the default-state routine, palettes, push buffers, `SetRenderState_Simple`'s NV2A method table and the kernel timer and DPC path; rexbox, at the commit pinned here, gained the physical window, SCSI pass-through, kernel timers, DPCs and `KeWaitForMultipleObjects`, DSOUND 4531 functions, and D3D8's 4531 render-state layout, push buffers, palettes, P8, NORMPACKED3 and declaration-only shaders, among others.

Submodules: `third_party/rexbox` is pinned to `ed2a8c1` on rexbox's task branch `i008-physical-window`, **a temporary pin** to move to a merge commit or tag once that branch is merged in rexbox (rexbox issues #7, #8, #9, #10, #12); `third_party/xboxrecomp` is v0.15.0 (`6376eb8`).

Known limits: fog is not drawn yet and vertex blending over several model views uses the first matrix, both the next task; the picture was checked with hidden-display frame dumps, and real play with a window, sound and input is not verified yet.

Verified: Win32 x86 Debug with no build errors and CTest 5/5 (rexbox probes 83 / 55 / 201 checks, two app smoke tests); `rect3.exe roms` (hidden, no audio) shows the title at frame 250 and the attract demo's 3D scene at frames 1900 and 2100.
