## reCT3 v0.0.3

이전 릴리스 **v0.0.2** 이후의 변경입니다(issue #5). **rexbox를 머지된 v0.0.4에 고정하고, 포그와 정점 블렌딩을 그립니다.**

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#5](https://github.com/reexec/reCT3/issues/5) | 포그와 정점 블렌딩(측정, rexbox 구현, 검증) | `01d39a2`, `63264be`, `c72c9bd` |

### 바뀐 것

* **submodule**: `third_party/rexbox`를 v0.0.4(`0fce514`, rexbox `main`의 머지 커밋)에 고정한다. v0.0.2의 작업 브랜치 임시 고정이 해소됐다.
* **분석**: CT3 데모의 포그 상태(EXP, density −0)와 스킨 모드(0, 1, 3, 5), 상태 내보내기 `sub_000FD590`의 포그 규칙, `SetRenderState_VertexBlend`의 SET_SKIN_MODE, `PBYTE4` 블렌드 가중치.
* **rexbox v0.0.4로 얻은 것**: 포그(데모에서는 계수 1이라 화면 변화 없음), 행렬 2~4개 정점 블렌딩.

### 확인한 것

| 구성 | 확인 |
|---|---|
| Win32 x86 Debug | 빌드 오류 0, CTest 5/5(rexbox probe 83 / 55 / 220, 앱 smoke 2개) |
| `rect3.exe roms`(hidden) | 셰이더 오류·"not drawn" 보고 없음, 블렌딩·포그 프로그램이 만들어짐, 어트랙트 데모 정상 |

### 알려진 한계

* 데모 시점이 실행마다 달라 같은 장면의 전후 비교는 하지 못했다. 게임 플레이의 포그와 인물 스키닝, 창 표시·소리·입력은 사용자 환경에서 확인한다.

## reCT3 v0.0.3 (English)

Changes since **v0.0.2** (issue #5). **rexbox is pinned to the merged v0.0.4, and fog and vertex blending are drawn.**

Resolved: #5, fog and vertex blending (measurements, the rexbox implementation, verification; `01d39a2`, `63264be`, `c72c9bd`).

Changes: `third_party/rexbox` is pinned to v0.0.4 (`0fce514`, the merge commit on rexbox's `main`), ending v0.0.2's temporary task-branch pin; the analysis records the demo's fog states (EXP, density −0) and skin modes (0, 1, 3, 5), the fog rules of the state flush `sub_000FD590`, `SetRenderState_VertexBlend`'s SET_SKIN_MODE and the `PBYTE4` blend weights; rexbox v0.0.4 brings fog (factor 1 in the demo, so no visible change) and vertex blending over two to four matrices.

Verified: Win32 x86 Debug with no build errors and CTest 5/5 (rexbox probes 83 / 55 / 220, two app smoke tests); `rect3.exe roms` (hidden) reports no shader error or "not drawn", builds the blending and fog programs and draws the attract demo correctly.

Known limits: the demo's timing differs between runs, so the same scene before and after was not compared; gameplay fog and character skinning, and a window, sound and input, are checked on the user's machine.
