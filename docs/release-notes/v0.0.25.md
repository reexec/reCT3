## reCT3 v0.0.25

이전 릴리스 **v0.0.24** 이후의 변경입니다(issue #25 후속). **Linux 실기에서 x86 빌드와 실행까지 확인합니다.** 코드는 바뀌지 않았고, 실기에서 만난 환경 문제 두 가지와 우회를 가이드에 적었습니다.

### 진행한 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#25](https://github.com/reexec/reCT3/issues/25) | Linux 실기의 x86: 빌드·CTest·실행 확인, `libxtst-dev:i386` 설치 우회, NVIDIA Wayland에서의 x86 창 우회 | `49f40e0`, `501eab5` |

### 바뀐 것

* 가이드 `docs/guides/linux-setup-and-build.md`
  * Ubuntu 26.04에서 `libxtst-dev:i386`(2:1.2.5-1ubuntu0.1)이 man 페이지 충돌로 설치되지 않으면 `sudo apt-get -o Dpkg::Options::=--force-overwrite install -y libxtst-dev:i386`로 설치한다(i386·amd64 판의 man 페이지만 다르고 헤더는 같다).
  * x86 빌드를 NVIDIA 드라이버(595.99.02)의 Wayland 세션에서 돌리면 창을 열지 못한다(`unable to create an EGL window surface`). 32비트 `libnvidia-egl-wayland2.so.1`의 결함이다. `SDL_VIDEO_DRIVER=x11`로 우회한다.
* 설계·작업 지시·작업 로그 i025의 후속 절, README 플랫폼 표.

### 확인한 것 (Ubuntu 26.04, GCC 15.2, RTX 4090)

| 구성 | 확인 |
|---|---|
| `regenerate.py` | 4,931/4,932 함수, 실패 0 |
| Linux x64 Release | 경고 0, CTest 7/7. 숨김 100초: 3D 데모 59.5~59.9 fps, 멈춤 없음 |
| Linux x86 Release | 경고 0, CTest 7/7. 숨김 100초(`SDL_VIDEO_DRIVER=x11`): 3D 데모 58.5~59.9 fps, 멈춤 없음 |

### 알려진 한계

* 실기의 창·오디오·게임패드는 아직 사용자가 확인하지 않았다.
* Wayland 실패 시 x11로 다시 여는 자동 폴백은 넣지 않았다(설계 i025 §6).

## reCT3 v0.0.25 (English)

Changes since **v0.0.24** (issue #25 follow-up). **The x86 build and run are checked on a Linux machine.** No code changed; the guide records two problems of the machine's environment and their workarounds.

Issue: #25, x86 on the Linux machine: build, CTest and run checked, a workaround for installing `libxtst-dev:i386` and one for the x86 window under NVIDIA on Wayland (`49f40e0`, `501eab5`).

Changes:

* The guide `docs/guides/linux-setup-and-build.md`:
  * When `libxtst-dev:i386` (2:1.2.5-1ubuntu0.1) does not install on Ubuntu 26.04 because of a man page conflict, install it with `sudo apt-get -o Dpkg::Options::=--force-overwrite install -y libxtst-dev:i386` (only the man pages of the i386 and amd64 packages differ; the headers are identical).
  * The x86 build cannot open a window in a Wayland session with the NVIDIA driver (595.99.02) (`unable to create an EGL window surface`), a defect of the 32-bit `libnvidia-egl-wayland2.so.1`; `SDL_VIDEO_DRIVER=x11` works around it.
* Follow-up sections in design, work order and work log i025; README's platform table.

Verified (Ubuntu 26.04, GCC 15.2, RTX 4090): `regenerate.py` lifts 4,931 of 4,932 functions with 0 failures; Linux x64 Release has 0 warnings, CTest 7/7, and a hidden 100 s run shows the 3D demo at 59.5–59.9 fps with no stop; Linux x86 Release has 0 warnings, CTest 7/7, and a hidden 100 s run (`SDL_VIDEO_DRIVER=x11`) shows the 3D demo at 58.5–59.9 fps with no stop.

Known limits:

* The window, audio and gamepad on the machine are not yet checked by the user.
* No automatic fallback that reopens with x11 after a Wayland failure (design i025 section 6).
